# Workforce Analytics Dashboard | Power BI

## 📊 Project Overview

The **Workforce Analytics Dashboard** is a data analytics project developed using Microsoft Power BI to analyze candidate and workforce-related information through interactive visualizations.

The project focuses on understanding workforce distribution based on experience, geographical locations, and job roles. It transforms raw candidate data into meaningful insights that support better data-driven decision-making.

## 🎯 Project Objectives

- Analyze workforce and candidate data.
- Understand candidate distribution based on experience.
- Identify the top 10 cities and states by candidate count.
- Analyze job roles across different experience categories.
- Present key workforce metrics through interactive visualizations.
- Improve data-driven decision-making through analytical insights.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Data cleaning and preparation.
- **Google Sheets** – Data management and organization.
- **DAX** – Calculated measures and analytical calculations, where used.

## 📈 Dashboard Features

- **KPI Cards:** Display key workforce metrics.
- **Experience Distribution:** Analyze candidates across experience groups.
- **Top 10 Cities:** Identify cities with the highest candidate representation.
- **Top 10 States:** Analyze geographical workforce distribution.
- **Job Role vs Experience:** Compare job roles across experience categories.
- **Interactive Visualizations:** Explore workforce data through dashboard filters and interactions.

## 🔍 Data Cleaning & Preparation

The dataset was prepared through the following steps:

1. Identifying and handling missing values.
2. Checking and removing duplicate records.
3. Correcting inconsistent data entries.
4. Standardizing data formats.
5. Organizing data for analysis and visualization.

## 💡 Key Insights

The dashboard helps explore:

- Workforce distribution across different experience levels.
- Geographical concentration of candidates.
- Candidate representation across different job roles.
- Relationships between job roles and experience categories.

*Specific numerical findings can be added after validating the dashboard results.*
